# Tools

Claude Code (Anthropic, Claude Opus 5.1), as a VS Code extension.

We used it as a learning aid. It explained eBPF, XDP, BPF maps and the Linux packet path to us, and it helped us put together a reference version of the load balancer that we could run in network namespaces, capture with tcpdump, poke at with bpftool, break and fix. Having something that worked end to end made the concepts click much faster than reading alone. The project in this repo is our own build, done after that.

No other AI tools were used.
